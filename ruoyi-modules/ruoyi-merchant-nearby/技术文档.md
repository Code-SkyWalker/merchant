# ruoyi-merchant-nearby 模块技术文档

## 1. 模块概述

### 1.1 模块简介
ruoyi-merchant-nearby 是 RuoYi-Vue-Plus 项目中的商户附近模块，主要提供基于地理位置的商户搜索、商品管理、订单处理、营销活动等核心业务功能。

### 1.2 技术架构
- **架构模式**: COLA（Clean Object-oriented and Layered Architecture）整洁分层架构
- **核心框架**: Spring Boot 3.5.7 + JDK 17
- **ORM框架**: MyBatis-Plus 3.5.14
- **缓存组件**: Redisson 3.51.0
- **权限认证**: Sa-Token 1.44.0
- **地理空间**: Redis GEO（基于Redisson实现）

### 1.3 模块结构
```
ruoyi-merchant-nearby/
├── ruoyi-merchant-nearby-adapter/        # 适配层（Web接口）
├── ruoyi-merchant-nearby-app/           # 应用层（业务逻辑）
├── ruoyi-merchant-nearby-client/        # 客户端层（DTO/CO定义）
├── ruoyi-merchant-nearby-domain/        # 领域层（核心业务模型）
├── ruoyi-merchant-nearby-infrastructure/ # 基础设施层（数据访问、外部依赖）
└── ruoyi-merchant-nearby-starter/       # 启动配置
```

## 5. 技术特性

### 5.1 地理位置搜索
- 基于Redis GEO实现高性能附近商户搜索
- 支持按距离排序和过滤
- 启动时自动预热地理位置缓存

### 5.2 价格计算引擎
- 责任链模式处理多种优惠叠加
- 支持优惠券、营销活动、运费、积分等计算
- 精确到分的金额计算

### 5.3 数据一致性
- 使用乐观锁防止并发更新
- 事务管理保证数据一致性
- 分布式锁处理并发场景

### 5.4 性能优化
- Redis缓存热点数据
- 数据库索引优化
- 分页查询减少数据传输
