# 快递100对接模块

## 概述
该模块实现了与快递100平台的对接功能，支持快递配置管理、订单创建、提交到快递平台以及物流跟踪等功能。

## 架构设计
采用DDD（领域驱动设计）架构模式，分为以下几层：
- **Adapter层**：API控制器，提供REST接口
- **Application层**：应用服务，协调领域服务和基础设施服务
- **Domain层**：领域模型和领域服务，包含业务逻辑
- **Infrastructure层**：基础设施服务，包括数据访问、外部API集成等

## 功能特性
- 快递配置管理：支持配置不同快递公司的API信息
- 快递订单管理：创建、提交、查询快递订单
- 物流跟踪：实时查询包裹物流信息
- 多租户支持：支持不同租户和商家的隔离
- 安全认证：集成系统安全认证机制

## 数据表
- `express_config`：快递配置表
- `express_order`：快递订单表

## API接口
- `/express/config`：快递配置相关接口
- `/express/order`：快递订单相关接口

## 依赖
- 快递100 SDK
- COLA架构框架
- MyBatis-Plus
- RuoYi-Vue-Plus基础组件

## 使用说明
1. 在快递配置表中添加快递公司API配置
2. 通过API创建快递订单
3. 提交订单到快递100平台
4. 查询物流状态
